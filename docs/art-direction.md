# アートディレクション基準 (M16.5)

モックアップ2枚 (`docs/playtest-2026-07-05/` の実測 before と対比する基準) から
書き出した目標のルック。以後のビジュアルパスはこの文書との目視比較で判定する。

## 目標のルック

- **地面**: 苔むした岩肌。緑がかった苔の粒感 + 岩の明度差のあるまだら。
  黒潰れしない (露出は昼間の屋外程度に明るく)。
- **粘菌ネットワーク**: 金色 (#E8B84B 系統) に光る脈。activity/flux が高い
  ほど明るい。ノードは光の粒 (放射グラデーション)。
- **Biomass 膜**: 縁が一段明るいリム (成長前線が光っている), 内側は
  半透明で下の地形が透ける。
- **水域**: 深みのある青、縁に明るいライン。
- **障害物**: 陰影のある岩、ベタ塗りにしない。
- **夜間トーン**: 暗くするのではなく青く沈める (黒潰れを避ける)。

## 実装 (2026-07-05, render.ts)

- **地形ベース色を「常時不透明」に変更**: 旧実装は近黒背景 + 淡い差分オーバーレイ
  だったため全体が黒潰れしていた。`TERRAIN_TONE` (ステージごとの shadow⇄sunlit
  2トーン) を `env.brightness` (光走性用フィールドを「日当たり」として視覚的に
  転用) で補間し、`env.moisture` で苔/砂の色味へ寄せる。
- **ハッシュノイズ (`hashNoise(x,y)`)** でセル座標から決定的な粒感を追加し、
  苔・岩のまだら模様を表現 (新しい sim フィールドは増やしていない)。
- **プラズマ膜**: `PLASMA_LOW/MID/HI` を金色系統へ (旧: 山吹寄りのくすんだ配色)。
  `PLASMA_RIM` で v (正規化 biomass) が低い帯域 (縁, 成長前線) を山型カーブで
  一段明るく光らせる。
- **ネットワーク発光**: `drawEdges` を2パス化。1パス目は
  `globalCompositeOperation: 'lighter'` + `shadowBlur` で低コストなぼかし
  グロー、2パス目が従来通りの芯 (crisp なストローク)。
- **性能**: `?debug` の perf HUD で draw 2.10ms (予算 3ms 以内) を確認。

## 検証

- 目視: `docs/playtest-2026-07-05/petri-day8-field.png` (旧) と、このパス後の
  スクリーンショット (要再撮影、`docs/playtest-2026-07-05/` に追記予定) を
  並べて「金色に光る網が苔むした地面を這っている」に見えるかを判定する。
- 自動: `e2e/visual.spec.ts` — 完全なピクセル差分スナップショットは
  seed が非決定的 (`game.ts` の `reset()` が `Math.random()` 由来) なため
  基準画像を固定できず、環境間の GPU/フォント差でも簡単に割れる。代わりに
  「黒潰れが再発していないか」を平均輝度の閾値 (>35) で検査する。
